# KileleTech ICT Platform

A complete ICT business platform built with **PHP, MySQL, and Bootstrap 5**.

## 🚀 Features
- **Custom Admin Dashboard** – Manage site settings, users, projects, and media.
- **E-Commerce Market** – Add products, track inventory, and handle customer orders.
- **Project Management** – Full CRUD (Create, Read, Update, Delete) for projects.
- **Reviews & Quotes** – Customer feedback and dynamic quote request systems.
- **Dynamic Site Settings** – Change logos, videos, social links, and text from the Admin Panel.

## 🛠️ Tech Stack
- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript, Bootstrap 5

## 📂 How to Run
1. Install XAMPP.
2. Clone this repository into `C:\xampp\htdocs\`.
3. Create a database named `kilelete_kilele_tech` in phpMyAdmin.
4. Import `database.sql`.
5. Update `includes/db.php` with your local settings.
6. Open `http://localhost/KileleTech-platform/`.
